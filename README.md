# Omar's Pie — v2.8.1

**From the familiar to the exceptional.**

A pizza topping randomizer with culinary-school depth, built for a Gozney Dome
(850–950°F, 60–90s) and Baking Steel (550°F, 4–6min) home setup. Pork-free /
halal throughout. Biga dough. Eight cuisines, three stores, two ovens.

**~165 ingredients · 49 Classics · 46 Chef's Touch rules · 30 full recipes**

## What it does

- **Engine** — cuisine-aware scoring with hard-conflict blocking, coverage and
  docking awareness for bianca builds, sauce-forward detection, and a
  cycling swap system on every slot.
- **Chef's Touch** — 46 curated, sourced pairing rules (Ottolenghi, Casa Moro,
  AVPN, taquería and kebab-house tradition). Fires only when a specific build
  earns it; silence over genericity.
- **The Classics** — 49 documented pies across Neapolitan, Levantine, Turkish,
  Greek, North African, Mexican, American, and Indian traditions, each with
  history and technique notes.
- **Library** — every ingredient described and sourced (Sara's Market,
  Central Market, Altin Grocery), with 30 expandable recipes.
- **Recipes** — cook mode (full-screen step-by-step with stopwatch), live
  Full/½/¼ ingredient scaling, and batch-yield badges.
- **Kitchen-proof** — keep-screen-awake toggle on the pizza and Library
  screens, shopping list with per-store routing and quantities, saved pies
  and meaningful-interaction history.
- **PWA** — offline-capable, installable, with an in-app update banner.

## Files

`index.html` · `style.css` · `data.js` · `app.js` · `sw.js` — deploy all five
together; the service-worker version bump triggers the update banner.
